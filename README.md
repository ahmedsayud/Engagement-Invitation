# دعوة خطوبة أحمد & آلاء 💍✨

موقع دعوة خطوبة إلكترونية تفاعلية فاخرة مبني باستخدام **Next.js 14** و **Tailored Luxury CSS**.

## ✨ الميزات والخصائص
1. **مغلف ثلاثي الأبعاد تفاعلي (3D Envelope)** مع ختم شمعي ملكي باسم العروسين (أ & آ).
2. **أنيميشن فتح المغلف** مع تناثر زينة الفرح (Confetti).
3. **مشغل موسيقى هادئة احتفالية** (Audio Player) يعمل تلقائياً مع فتح الدعوة مع إمكانية كتم الصوت أو تشغيله.
4. **خلفية نجوم وذرات ذهبية متحركة** (Golden Starry Canvas).
5. **الأسماء بخط الثلث/الرقعة العربي الفاخر** وتأثير الشيمر الذهبي (Golden Shimmer).
6. **عداد تنازلي مباشر (Live Countdown)** لموعد الحفل (يوم الخميس القادم).
7. **زر إضافة الموعد إلى تقويم Google**.
8. **معرض صور الخطوبة** مع إطارات ملكية وتأثيرات بصرية مميزة.
9. **تفاصيل المكان (أمام البيت)** مع بطاقة خريطة وزر مباشر للملاحة في خرائط Google.
10. **زر تأكيد الحضور والمباركة عبر واتساب** مع رسالة تهنئة جاهزة وجميلة.
11. **زر إطلاق ألعاب نارية وزينة تفاعلية (Celebration Fireworks)**.
12. **إعدادات Open Graph كاملة** لظهور معاينة كارت شيك على الواتساب ووسائل التواصل.

## 🚀 التشغيل محلياً (Local Development)

```bash
npm install
npm run dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000).

## 📦 خطوات الرفع على GitHub والنشر على Vercel

### 1. تهيئة مستودع Git ورفعه على GitHub:
```bash
git init
git add .
git commit -m "Initial commit: Ahmed & Alaa Engagement Invitation"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ahmed-and-alaa-engagement.git
git push -u origin main
```

### 2. النشر على Vercel:
1. ادخل على [Vercel.com](https://vercel.com) وسجّل الدخول بحساب GitHub.
2. اضغط على **"Add New Project"** ثم اختر مستودع `ahmed-and-alaa-engagement`.
3. اضغط **Deploy** وخلال ثوانٍ سيكون الموقع لايف برابط جاهز للإرسال والمشاركة على الواتساب!
